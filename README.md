# 🛍️ Customer Behaviour Analysis

## 📌 Project Overview
Customer Behaviour Analysis is a data analytics project that focuses on understanding customer purchasing patterns, preferences, and shopping habits. The project analyzes customer shopping data to identify meaningful insights that help businesses improve customer satisfaction, optimize marketing strategies, and make data-driven decisions.

## 🎯 Project Objectives
- Analyze customer purchasing behaviour and shopping patterns.
- Identify popular product categories and frequently purchased items.
- Understand customer preferences based on age and gender.
- Analyze revenue and purchase trends.
- Study the impact of discounts and promotional offers.
- Identify customer subscription patterns.
- Generate meaningful business insights using data visualization.

## 🛠️ Technologies Used
- **Python** – Data cleaning and exploratory data analysis.
- **Pandas & NumPy** – Data manipulation and analysis.
- **PostgreSQL** – Data storage and SQL-based analysis.
- **Power BI** – Interactive dashboard creation and visualization.
- **Jupyter Notebook** – Python development and analysis.

## 📂 Project Workflow
1. **Data Collection:** Import the customer shopping dataset.
2. **Data Cleaning:** Handle missing values, remove inconsistencies, and prepare the dataset.
3. **Exploratory Data Analysis (EDA):** Explore customer demographics, purchasing patterns, and product preferences.
4. **SQL Analysis:** Use PostgreSQL queries to extract meaningful business insights.
5. **Data Visualization:** Create interactive dashboards using Power BI.
6. **Insights Generation:** Identify important trends and provide data-driven recommendations.

## 📊 Key Analysis Areas
- Customer demographics analysis.
- Product category analysis.
- Purchase amount and revenue analysis.
- Seasonal shopping trends.
- Discount and promotional code analysis.
- Customer subscription analysis.
- Payment method preferences.
- Customer purchase frequency.

## 💡 Expected Outcomes
- Better understanding of customer purchasing behaviour.
- Identification of high-performing product categories.
- Insights into customer spending patterns.
- Understanding of promotional offers and discount effectiveness.
- Data-driven recommendations for improving business performance.

## 📁 Dataset Information
The project uses a Customer Shopping Behaviour dataset containing 3,900 customer records and 18 attributes, including:

- Customer ID
- Age and Gender
- Item Purchased
- Category
- Purchase Amount (USD)
- Location
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Previous Purchases
- Payment Method
- Frequency of Purchases

## 🚀 Conclusion
This project demonstrates how data analytics tools and technologies can be used to transform raw customer shopping data into meaningful business insights. It provides practical experience in Python, SQL, PostgreSQL, and Power BI while supporting better business decision-making.
